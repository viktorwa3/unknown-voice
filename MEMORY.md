# MEMORY — The Unknown voice (DbD) / ElevenLabs + SoX

## Global flow

```
ElevenLabs Voice Design (2 голоса: male + female, ОДНА фраза)
        ↓ export (History → MP3/WAV)
   ffmpeg  (→ 44.1kHz / 16-bit / mono wav)
        ↓
   SoX     (4 слоя → десинк pad → -m микс → характер)
        ↓
   unknown_chorus.wav
```

Обратно в ElevenLabs ничего не заливается. DAW/SoX — конечная станция.

## Решения

- **Хор из промпта не генерится.** Voice Design отдаёт ОДИН голос. Хорную
  текстуру можно частично запечь в тембр (`chorus`, `overlapping`, `detune`,
  `unison`, `swarm` в промпте), но настоящий десинк — только пост-обработкой.
- **Voiceover Studio** позволяет стакать дорожки на таймлайне вручную, но
  БЕЗ per-track volume / EQ / pitch / reverb. Даёт ~60%, остальное — SoX.
- **Женский голос не оставлять "как женский"** — иначе выходит дуэт, а не
  сущность. Слой GHOST тащит женский вниз до мужского регистра.

## Caveats / known bugs

| Проблема | Причина | Фикс |
|---|---|---|
| `no handler for file extension 'mp3'` | Виндовый SoX без libmad | Конвертить через ffmpeg, не SoX |
| `Output file does not contain any stream` | Забыт `-i` у ffmpeg — файл считается output | `ffmpeg -i in.mp3 out.wav` |
| `WARN reverb/equalizer clipped N samples` | Эффекты накидывают гейн > 0 dBFS | `gain -6` в начале цепочки + `gain -n -1` в конце |
| "Звучит как чел с эхом" | `reverb` — это комната, не монстр. `pitch` не двигает форманты | `speed` + `tempo` (формантный сдвиг) + `overdrive` + `pad` десинк + слои |
| WAV не виден в UI ElevenLabs | Качается из **History**, не из кнопки под генерацией | History → выбрать формат |
| WAV мыльный / отсутствует | 44.1kHz PCM/WAV = **Pro tier и выше**. Free/Starter/Creator → WAV конвертнутый из 128kbps | Качать MP3, конвертить локально ffmpeg — для убитого питчем голоса разницы нет |
| `is not digitally signed` / `PSSecurityException` | ExecutionPolicy = **AllSigned** (часто из GPO) | `powershell -ExecutionPolicy Bypass -File .\script.ps1 ...`; проверить scope через `Get-ExecutionPolicy -List`; `Unblock-File` если файл из инета |
| `Unexpected token 'Ð°Ð¹Ð»Ð°:'` / `string is missing the terminator` | **PS 5.1 читает BOM-less .ps1 как ANSI (cp1251)**, а файл в UTF-8. Кириллица в строках рвёт парсер | Скрипты держать **ASCII-only**. Либо пересохранить в UTF-8 **with BOM**, либо гонять через `pwsh` (PS 7 читает UTF-8 по умолчанию) |
| SoX не парсит `speed 0,82` / кривые числа | PS интерполяция `[double]` в строку использует **текущую культуру** (nb-NO → запятая как десятичный разделитель) | Пин `[Threading.Thread]::CurrentThread.CurrentCulture = InvariantCulture` в начале скрипта. | `NativeCommandError` от SoX при варнингах | PS 5.1: нативный stderr под `$ErrorActionPreference='Stop'` кидает **до** проверки `$LASTEXITCODE` | В `Invoke-Sox` локально `$ErrorActionPreference='Continue'`, полагаться на `$LASTEXITCODE` |
| Мусор/алиасинг на высоком `-Dread` | При `Dread>~2` `ghostSpeed` уходит в 0.16 → tempo-restore ~6x = артефакты, а не жуть | Скорости клампятся (low>=0.6, high<=1.6, ghost>=0.55). Рабочий диапазон Dread ~**0.6–1.6** |

## Ключевое знание по SoX

- `pitch` — двигает высоту, **не трогает тембр** → звучит как простуженный человек.
- `speed` + обратный `tempo` — двигает **форманты**, длительность возвращает на место → звучит как НЕ человек. Это то, что делает эффект.
- `pad` — реальный временной сдвиг слоёв = "несколько глоток".
- `-m` — микс нескольких файлов, разную длину добивает тишиной.
- `overdrive` — мокрая гортанность.
- `bandpass 1200 3q` + провал на 3.5k — "полый, изнутри тела".

## Скрипт

`Build-UnknownVoice.ps1 -MaleFile male.mp3 -FemaleFile fem.mp3 [-Dread 1.4] [-KeepStems]`

- `-Dread` (0.1–3.0 валидация, но полезно **0.6–1.6**) — общий множитель жути, крутит speed/overdrive/pad разом. Производные скорости клампятся, чтобы не было алиасинга.
- `-FemBoost` (0–12 dB, деф. 4) — поднимает женские слои. Полный буст идёт на **HIGH** (узнаваемый женский шёпот, `gain -n -12+FemBoost`), GHOST лифтится частично (`*0.6`), т.к. читается как мужской.
- `-Grit` (0–3, деф. 1.0) — `overdrive $gritDrive 30` в финальной цепочке + второй голос в `chorus`. Дисторшн уже в характере, не в слоях. Chorus gain-in/out убран с 0.7/0.9 до 0.6/0.85, чтобы овердрайв гритил, а не превращался в шум.
- `-Drag` (0.75–1.0, деф. 0.92) — общий драул через `tempo` на финале. **tempo, не speed** — тянет подачу, не трогая питч/форманты (speed на 0.75 убил бы всю формантную работу слоёв в мультик).
- `-Pulse` (0–3, деф. 1.0, 0=off) — периодическая дисторшн. У SoX нет time-varying overdrive за один проход, поэтому: жёстко перегруженный сайдчейн из `mix` → медленный глубокий `tremolo 0.3 90` (свелл ~раз в 3.3с) → подмешивается ПОД чистый голос через `-m`. Голос периодически "ломается". `$pulseLevel` рулит громкостью сайдчейна.
- `-Warble` (0–3, деф. 1.0, 0=off) — питч-дрифт "не может удержать ноту". Медленный глубокий одноголосый `chorus 0.7 0.9 40 0.4 0.2 $warbleDepth -s` в character-цепочке (строится динамически, при 0 не добавляется). depth = 3.5*Warble мс.
- `-Wide` (0–1, деф. 0.6, 0=mono) — **истинное стерео панорамированием слоёв на этапе микса** (не Haas). Каждый слой → `remix 1v<L> 1v<R>` (equal-power, гейном → **mono-compatible, без гребёнки при даунмиксе**). GHOST+LOW влево, HIGH вправо, MID центр; разброс масштабируется `$Wide` (через `Get-PanGain`). Вся цепочка после микса идёт в стерео (reverb/chorus дают доп. ширину). Wide=0 → всё в центр, финал схлопывает `remix 1-2` в честное моно. Старый Haas/`-M` выпилен (лип к одной стороне + гребёнка при моно-сумме).
- `-Rumble` (0–6, деф. 1.0, 0=off) — саб-бас подложка. Октава вниз (`lowpass 110` → `pitch -1200` → `lowpass 80` → `overdrive`) **из самого голоса**, поэтому пульсирует с речью, а не гудит. Уровень `min(-4, -20+4*Rumble)` dB (−16 @1), **потолок −4 dB** (Rumble≥4) — саб не клипует и не хоронит голос. Моно, до стерео-разворота. Слышно на сабе/наушниках, на ноутбучных динамиках почти нет — это норм.
- `-Crush` (0–3, деф. 0.0/off) — биткраш "сломанная передача". Параллельная копия: `-b 8 -e unsigned-integer` (квантование при записи) + `rate $crushRate → 44100` (децимация/алиасинг) + overdrive + highpass 250, подмешивается тихо (`-18+4*Crush`). crushRate = 9000-2000*Crush (ниже = грязнее). Держим 8-бит (4-бит не валидный PCM WAV).
- `-Reverb` (0–3, деф. 1.0, 0=dry) — **окказиональный ревер**. Постоянный `reverb 75...` убран из character-цепочки (был washy/ugly). Вместо него wet-only сайдчейн (`reverb -w 75 50 100 100 20 0`) гейтится медленным `tremolo 0.15 90` (свелл ~раз в 6-7с) и подмешивается под голос. Комната приходит и уходит, а не гудит постоянно. `$verbLevel = min(-2, -12+4*Reverb)`.
- `-Preverb` (0–3, деф. 0.0/off) — reverse-reverb пре-свелл ("сейчас заговорит"). Пост-обработка готового $OutFile: `reverse → reverb $preverbAmt 50 100 100 0 0 → reverse`. Хвост ревера флипается и ведёт ПЕРЕД онсетом. Дефолтный (не wet-only) ревер сохраняет сухой голос → добавляется только свелл. **Сдвигает онсет позже** на длину свелла + удлиняет файл. `$preverbAmt = min(90, 40+15*Preverb)`.
- Хвост цепочки (**стерео уже с этапа микса**): pan-mix → character (без ревера) → Pulse → Rumble → Crush → **Reverb (гейтед)** → `$mono` → финал (Wide) → **Preverb пост-проход**. Каждый слой правит `$mono`. Wide=0 → финал схлопывает в моно (`remix 1-2`).
- `-KeepStems` — оставить слои в `_stems/` для ручного разбора.
- ffmpeg/SoX **автодетект**: ffmpeg берётся из `./ffmpeg/bin/` рядом со скриптом → PATH; SoX по `-SoxPath` → PATH. Явные `-FfmpegPath`/`-SoxPath` перекрывают.
- Культура пинится в InvariantCulture в начале — иначе SoX ловит запятую в числах (см. caveats).
- Входные фразы у male/female должны быть **идентичны по тексту**, иначе микс
  превратится в бормотание двух разных существ.
